Note: The Summit X15 file says storage and battery options "will be announced closer to launch." Those values may change the picture once published.

## Where competitors are stronger

- Vantage Pro 16 has the larger GPU memory (24 GB vs 16 GB), the larger battery (99 Wh vs 86 Wh) and the fastest display refresh (165 Hz vs 120 Hz).
- Summit X15 has the larger, higher-resolution display (15.6-inch, 3840 x 2400 vs 14-inch, 2880 x 1800).

## 3 differentiators for Aurora 14

1. Most memory headroom, and you can upgrade it. Aurora 14 supports up to 128 GB, against 96 GB on Summit X15 and 64 GB on Vantage Pro 16. Its memory is user-upgradeable. Vantage Pro 16's is soldered. The Summit X15 file does not say whether its memory is upgradeable.

2. Lightest of the three. At 1.65 kg, Aurora 14 is 0.30 kg lighter than Summit X15 (1.95 kg) and 0.65 kg lighter than Vantage Pro 16 (2.30 kg). It also has the highest CPU core count in the table (16 vs 12 and 14), so the lower weight does not come with a smaller core count.

3. Newest high-speed connectivity and the most storage on record. Aurora 14 has 2 x Thunderbolt 5, where Summit X15 lists Thunderbolt 4. It also adds an SD card reader, which the Summit X15 file does not list. Its 4 TB maximum storage is double the 2 TB of Vantage Pro 16. Summit X15 storage and Vantage Pro 16 ports are not stated, so those comparisons cannot be made yet.
