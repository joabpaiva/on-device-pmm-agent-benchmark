# Workstation Comparison: Aurora 14, Summit X15, Vantage Pro 16

Sources: inputs/t6/aurora14.md, inputs/t6/summit_x15.txt, inputs/t6/vantage_pro16.csv

| Attribute | Aurora 14 | Summit X15 | Vantage Pro 16 |
|---|---|---|---|
| CPU | Helix H9 AI, 16 cores | Helix H7 AI, 12 cores | Corvex X12, 14 cores |
| GPU | Vireo V8000 Pro, 16 GB dedicated memory | Vireo V6000, 8 GB graphics memory | Vireo V9000, 24 GB |
| Max memory | 128 GB (user-upgradeable) | 96 GB | 64 GB (soldered) |
| Max storage | 4 TB NVMe | not stated | 2 TB |
| Display | 14-inch OLED, 2880 x 1800, 120 Hz | 15.6-inch OLED, 3840 x 2400, 60 Hz | 16-inch IPS, 2560 x 1600, 165 Hz |

| Ports | 2 x Thunderbolt 5, 1 x USB-A, HDMI 2.1, SD card reader | 2 x Thunderbolt 4, 1 x USB-A, HDMI 2.1 | not stated |

Notes on "not stated":
- Summit X15 storage and battery: the source says these "will be announced closer to launch."
- Vantage Pro 16 ports: the CSV has no ports row.

## 3 differentiators for Aurora 14

1. Most memory headroom, and you can upgrade it.
   Aurora 14 supports up to 128 GB, against 96 GB for Summit X15 and 64 GB for Vantage Pro 16. The Aurora 14 sheet says its memory is user-upgradeable. The Vantage Pro 16 sheet says its memory is soldered.

2. Lightest of the three.
   At 1.65 kg, Aurora 14 is 0.30 kg lighter than Summit X15 (1.95 kg) and 0.65 kg lighter than Vantage Pro 16 (2.30 kg). Both competitors have larger screens (15.6 and 16 inches), so the difference partly reflects the 14-inch size.

3. Newest Thunderbolt generation and the highest core count listed.
   Aurora 14 lists 2 x Thunderbolt 5. Summit X15 lists Thunderbolt 4. Aurora 14 also has an SD card reader, which the Summit X15 sheet does not list. Its CPU has 16 cores, against 14 and 12. Core count is the only CPU data in the files, so this is not a performance claim. The Vantage Pro 16 ports are not stated, so no port comparison is possible there.

## Where competitors lead (for honest positioning)

- Vantage Pro 16 has the largest GPU memory (24 GB vs 16 GB), the largest battery (99 Wh vs 86 Wh) and the fastest display refresh rate (165 Hz vs 120 Hz).
- Summit X15 has the highest display resolution (3840 x 2400). Aurora 14 has a faster refresh rate than Summit X15 (120 Hz vs 60 Hz).
- Storage and battery cannot be compared with Summit X15 until those specs are announced. Product management could confirm them.
